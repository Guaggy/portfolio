A small display that sits above my desk and shows what I need during the day.

## What it does

- Bench light, focus timer and habit buttons
- Tasks and calendar
- Alerts when Claude Code needs input
- Pi and Pi-hole stats, plus a screensaver with quotes and pixel art
- Connects over WiFi only

## Hardware and software

- LilyGO T-Display S3 (ESP32-S3, built-in colour screen)
- PlatformIO with Arduino core 3.2.1
- The repository's README is a hands-on setup guide
